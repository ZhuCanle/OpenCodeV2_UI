OpenCode V2 UI

OpenCode V2 UI is an open-source AI coding agent integration that brings the power of opencode.ai directly into your JetBrains IDE development workflow.

It is a community derivative of OpenCode UI by LaiZhou (MIT License), extended with opencode v2 support. It uses its own plugin id and keyboard shortcuts, so it can be installed alongside the original.

Download: Get the latest release

Key Features

  • Quick Launch: Attach to the local opencode v2 background service (discovered and authenticated automatically) or connect to a remote opencode serve instance, with a single shortcut (Cmd+Shift+Esc / Ctrl+Shift+\). Connection settings are remembered automatically.
  • Context Sharing: Seamlessly send code selections or file references (with line numbers) from your editor or project view directly to the AI agent (Opt+Cmd+Shift+K).
  • Diff Review: Automatically review AI-generated code changes in chronological order. Title shows progress (e.g., "1 of 5"). Accept writes and stages changes; Reject restores the baseline. Both actions auto-advance to the next file.
  • Notifications: Get system-level alerts when AI tasks complete, so you can focus on other work while OpenCode runs.
  • Auto-Resume: New terminals automatically restore your last session context - pick up right where you left off.
  • Web UI Mode: Tick "Use web interface" in the connection dialog to open the opencode web UI in an IDE tab (JCEF) instead of the terminal.
  • Smart Links: Click file paths in the terminal (e.g., @src/main.kt#L10-20) to jump directly to the code.

Tip: To receive desktop notifications when AI tasks complete, please ensure your OS allows notifications for the JetBrains IDE. (Mac: System Settings > Notifications > IntelliJ IDEA)


Follow these steps to set up and start using the OpenCode V2 UI plugin:

  1. Install a compatible JetBrains IDE (version 2026.2 or later).
  2. Install the opencode v2 CLI: This plugin acts as a bridge to the CLI tool and targets opencode v2:
    brew install anomalyco/tap/opencode-v2 (macOS / Linux) · other platforms: opencode.ai/download
    Note: v1 (opencode-ai on npm, or the opencode Homebrew formula) conflicts with v2 — both install an opencode binary — so keep only one installed.
  3. Ensure Git is installed: The plugin uses local git commands for managing changes.
  4. Launch your IDE and ensure the plugin is enabled.
  5. Press Cmd + Shift + Esc (Mac) or Ctrl + Shift + \ (Windows/Linux) to launch your first session.

Usage and Shortcuts

  • Connect/Launch: Cmd + Shift + Esc (Mac) / Ctrl + Shift + \ (Win/Linux) - Opens the connection dialog: attach to the local background service or connect to a remote server.
  • Add Context: Opt + Cmd + Shift + K (Mac) / Ctrl + Alt + Shift + K (Win/Linux) - Sends file references/selection to the terminal.

Diff Viewer Guide

  • Order: Diffs are presented in the order they were generated (chronological). Title shows progress (e.g., "1 of 5").
  • Navigation: Use ← / → arrows to switch between modified files.
  • Jump Changes: Use ↑ / ↓ to jump between specific changes in the current file.
  • Accept: Writes AI changes to disk, stages the file (git add), and auto-advances to the next file.
  • Reject: Restores the file to its pre-edit state and auto-advances to the next file.
  • Local Modified: The diff title shows (Local Modified) when your file differs from AI output.

The plugin automatically creates snapshots in your IDE's Local History for safety.

Plugin Compatibility

Complementary Plugins: This plugin requires the Terminal plugin (bundled by default).
