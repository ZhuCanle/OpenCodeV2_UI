## 1.3.7

### Fixes

- **The first launch no longer logs "This method is forbidden on EDT" (issue #3).** On IntelliJ
  2026.2 `TerminalProjectOptionsProvider.getShellPath()` runs `runBlockingMaybeCancellable`, which
  blocks and is forbidden on the Event Dispatch Thread. The plugin read it inside the `invokeLater`
  that opens the terminal tab, so the first OpenCode launch of every IDE session logged an
  `IllegalStateException`. The shell path is now resolved on a background thread and the command is
  typed into the terminal on the EDT afterwards.
