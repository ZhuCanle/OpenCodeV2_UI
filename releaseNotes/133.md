## 1.3.3

### Fixes

- **Local sessions authenticate on Windows again.** opencode v2 keeps its files in the XDG config
  directory (`~/.config/opencode`, or `$XDG_CONFIG_HOME/opencode`) on every platform, including
  Windows. The plugin only looked in `%APPDATA%\opencode` there, so it could not read the service
  password and the local connection failed to authenticate. It now reads the XDG location first and
  keeps `%APPDATA%\opencode` as a legacy fallback.
