## 1.2.1

### New Features

- **"v2" brand mark**: the plugin logo (Plugin Manager) and the tool window / action icons now
  carry a `v2` mark knocked out of the bottom-right corner of the opencode symbol, so this plugin is
  easy to tell apart from the upstream `OpenCode UI` plugin when both are installed.

### Fixes

- The tool window / action icons were invisible in light themes. They are now theme-aware: dark ink
  on light themes, white ink on dark themes (the platform picks `opencode_dark.svg` automatically).

### Notes

- This build is the **unofficial** v2-only derivative of
  [OpenCode UI](https://github.com/LaiZhou/OpenCode_UI). Source:
  <https://github.com/ZhuCanle/OpenCodeV2_UI>.
