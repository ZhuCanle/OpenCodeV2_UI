## 1.2.2

### New Features

- **"v2" brand mark**: the plugin logo (Plugin Manager) and the tool window / action icons now
  carry a `v2` mark knocked out of the bottom-right corner of the opencode symbol, so this plugin is
  easy to tell apart from the upstream `OpenCode UI` plugin when both are installed.
- **Labels say v2**: the context menu entries read `Add lines to OpenCode V2 Terminal` (editor) and
  `Add to OpenCode V2 Terminal` (Project View); the Tools menu entry reads `Open OpenCode V2`.

### Changes

- **Keyboard shortcuts are back to the upstream defaults**: `Cmd+Esc` / `Ctrl+\` for quick launch and
  `Opt+Cmd+K` / `Ctrl+Alt+K` for sending context. If the original `OpenCode UI` plugin is installed
  as well, rebind one of the two in **Settings → Keymap**.
- The tool window icon now uses the full 16×16 box (the upstream `viewBox` left a sixth of the
  height empty), so the mark and the `v2` mark stay readable on HiDPI displays.

### Fixes

- The tool window / action icons were invisible in light themes. They are now theme-aware: dark ink
  (`#0F0F0F`) on light themes, the platform's dark-theme ink (`#DFE1E5`) in dark themes; the
  platform picks `opencode_dark.svg` automatically via the `_dark` suffix.

### Notes

- This build is the **unofficial** v2-only derivative of
  [OpenCode UI](https://github.com/LaiZhou/OpenCode_UI). Source:
  <https://github.com/ZhuCanle/OpenCodeV2_UI>.
