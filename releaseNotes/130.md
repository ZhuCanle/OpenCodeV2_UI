## 1.3.0

### New Features

- **IntelliJ Platform 2024.2+ support** (`since-build 242`). The plugin is now compiled against
  IntelliJ IDEA 2024.2 instead of 2026.2, so:
  - the bytecode targets **JVM 21** and loads on the JBR 21 that 2024.2 – 2025.x ship with
    (previously it was JVM 25 bytecode, which those IDEs cannot load at all);
  - only APIs available in 2024.2 are referenced, so nothing breaks when a newer IDE is not
    installed.
  Compatibility with the current 2026.x releases is checked with the Plugin Verifier instead of
  being assumed.

### Fixes

- **Quick launch is usable on macOS again.** It used to be bound to `Cmd+Esc`, a keystroke the IDE's
  own `Vcs.CombinedDiff.ToggleCollapseBlock` action already owns, so only one of the two could ever
  fire and the shortcut looked dead. It is now `Cmd+\` (the macOS form of `Ctrl+\`, which stays the
  Windows/Linux binding), with `Shift+Cmd+Esc` as a second macOS shortcut.

### Notes

- The optional **JCEF web tab** is registered through the `com.intellij.modules.jcef` module, which
  only exists from 2026.2 on (before that, JCEF is part of the platform and has no module id of its
  own). On 2024.2 – 2025.x the plugin therefore runs in **terminal mode only**; every other feature
  works as before.
- Builds provision a JDK 21 toolchain automatically (Gradle toolchain + foojay resolver), so no
  manual JDK 21 install is needed.
