## 1.3.6

### Fixes

- **The diff tab now opens in the window that owns the change.** With several IDE windows open,
  the diff of a file change could appear in another window — usually the one that happened to be
  focused. The opencode event stream is **not** filtered by its `directory` query parameter: every
  subscriber receives every directory's events, each tagged with `location.directory`, and the
  plugin dispatched all of them. A window therefore reacted to another project's session and showed
  that session's diff. Frames are now filtered by `location.directory` before dispatch, comparing
  paths in a separator- and platform-independent way (and through their canonical form, so symlinks
  still match).
